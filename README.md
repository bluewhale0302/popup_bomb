# 팝업 지옥 서바이벌

평범하게 웹사이트를 둘러보던 중 광고가 갑자기 끼어드는 상황을 그린 브라우저 생존 게임 프로토타입입니다. 사이트마다 광고의 공격 방식이 다르며, 광고를 제때 처리해 브라우저 체력과 페이지를 지켜야 합니다.

## 맵과 플레이 방식

### YouTube

- 영상 재생을 시작하면 잠시 뒤 광고가 영상 위에 나타납니다.
- 광고의 건너뛰기 버튼이 활성화되면 클릭해 영상 재생을 이어갑니다.
- 광고를 방치하면 브라우저 체력이 감소합니다.

### 나무위키

- 브라우저 위쪽의 나무위키 탭을 누르면 문서 페이지로 이동합니다.
- 일정 시간이 지나면 문서 양옆에 광고가 나타납니다.
- 광고를 방치하면 문서 내용이 광고 문구로 오염되고 브라우저 체력이 감소합니다.
- 양쪽 광고의 닫기 버튼을 누르면 문서가 원래 내용으로 복구됩니다.

맵을 오가도 체력, 점수, 레벨, 경험치는 유지됩니다. 광고를 처리해 점수와 경험치를 모으면 레벨이 올라갑니다. 브라우저 체력이 0이 되면 게임이 종료됩니다.

## 기술

- HTML, CSS, Vanilla JavaScript
- 외부 라이브러리 및 빌드 도구 없음
- 데스크톱 및 모바일 화면 대응
